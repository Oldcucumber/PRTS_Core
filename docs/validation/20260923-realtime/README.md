# Web 实时小脑验证

本次验证跨 2026-09-23／24（Asia/Shanghai）。

- session-short.json：65 秒真实模型联合运行。相机输入为既有录像首帧经浏览器采集 API 重复供帧；麦克风输入为本地 TTS 合成的中文短句。四类口令均执行；一次重复口令被半双工截断为「停导航」，未执行。此结果不是用户口音／噪声准确率评估。
- static.json：仓库子路径、Service Worker 隔离、WebGPU、WASM、无隔离时的视觉回退、同站点资源。
- camera.json / camera-selection.json：模拟传感器的完整视野、旋转、设备切换及资源释放。
- lifecycle.json：初始化取消、麦克风拒绝、显式仅视觉模式与后台事件。

所有模型真实执行，未用固定识别结果替代推理。声音验证基于设备本地 TTS 的开始／结束回调，不代表物理扬声器声压或人耳可听度验证。没有实体摄像头的现场行走、盲人参与或 iPhone 真机测试；JS heap 趋势不包含所有 WASM／GPU 内存。

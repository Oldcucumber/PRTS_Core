# PRTS Core：剩余额度内的快速原型

2026-09-22，用户确认目前周额度约剩 20%。本文件的架构取舍优先于此前以 OCR 字段规则主导等待任务的描述。

交付目标：复用已有导航、相机/PCM 输入、ASR、TTS 与原生模型运行时，实现由多模态大脑决定等待事件、小脑持续导航的可运行桌面原型。提供 ZIP、实际模型输出与录像、截图、原理图、Apple 集成说明。原型完成不等于完整导盲产品验收。

## 最小闭环

1. 大脑接收用户目标、当前画面、最近观测记录、环境语音转写及可选 OCR/检测工具结果，决定继续观察、目标出现或需要澄清。OCR 与检测不再决定等待任务是否完成。
2. 小脑独立处理地面、不可通行区域和路径。共享事件层维护任务版本、观测时间、播报优先级；紧急导航提示可抢占普通回答，取消/切换目标后丢弃旧结果。
3. 连续回放验证非 912 线路、相同画面不同目标、柜台/价格与叫号区别，以及取消、换目标和导航并行。先保存原始失败，再有限修正，不追求把每个测试调成通过。

## 额度与范围

- 剩余工作精力约一半用于大脑闭环，四分之一用于真实模型验证，四分之一留给修复、打包和交接。账户百分比不是精确 token 预算，检查点复查用量。
- 优先复用已下载模型和真实素材。允许为解决已证实的大脑能力问题做有目的的模型或推理调整，不为节省额度删除大脑，也不重复无新增价值的长测试。
- Python 为本次可执行参考。Apple 提供接口/原生运行时来源和迁移说明；没有 Apple 硬件，不声称完成 iOS 编译、性能或实际空间 AR 验证。
- 8 GB 是整套目标。已有旧架构桌面测量可作背景，新的大脑闭环必须单独标注实测范围；假定的前端内存预留不能写成实测。
- 当能力不足时明确交付失败样例和当前边界，不以更多文字报告替代可运行原型。

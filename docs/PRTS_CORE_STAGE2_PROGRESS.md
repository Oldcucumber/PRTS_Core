## 当前分工

感知执行任务已冻结其报告与结果，并停止实验。根任务继续导航、连续交互、CPU/DirectML 集成、移植和证据审计。原感知算法及第一版结果保持可追溯，根任务对 ONNX 运行器的独立检测与 provider 配置改动另行记录。

## 已核实的外部条件

当前机器为 Windows，无 Apple 硬件或 Xcode。已成功编译并实际调用 PRTS 原生 CPU VLM C ABI；使用固定版本的 llama.cpp-omni，Python ctypes 与 Swift 绑定共用该接口。Swift 的相机、PCM、SenseVoice、原生 VLM、感知、任务/路线状态与系统播报已接入统一 PRTSCoreSession 源码。20 个 Swift 文件通过语法树检查；这不包含类型检查、链接或设备执行，没有在 Mac 编译。

用户已提供临时高德 Key，仅存入被 Git 忽略的本机密钥文件，不纳入 ZIP 或文档。真实 POI 检索与步行 API 已成功，得到武汉长岛至江夏大道长岛公交站的六段路线。此前模糊地点检索误选远处同名候选的返回也保留，用于验证地点确认的必要性。这些地图结果尚未与实拍视频的真实位置轨迹对齐，不能作为现场 AR 定位证据。

既有公开片段包含头部视角，第二版不能误标为胸前实拍。感知任务的独立人工标签评估与连续胸前路径回放分开报告。

## 已完成的第二阶段证据

最新补充：`regression-v3/` 开发回归 7 个公交目标与 23 个干扰请求全部符合预期；`holdout-v3-first-pass/` 新照片中 101 成功、101X 漏报，站牌及残缺 LED 反例不触发。首次结果已冻结，不能将后续调试改写为独立通过。`bus-dml-v5/` 原速连续相机 61/61 帧，实际用户语音与 Q5/有界 OCR 组合确认 912，证据年龄 2.937 秒；最终时间线演示已生成并完整解码。

真实地图 endpoint 审计发现“坐标 + POI ID”把终点吸附到距确认站点 86.3 米的位置；已修正为以确认坐标请求并检查最终距离。新真实坐标路线终点距 POI 0.38 米。`maps/route-replay/` 用真实几何及明确标注的 627 个仿真位置演示候选确认、转弯、到达后等待 903，非现场 GPS 或 AR 注册。
